# Habit Streaks

- **Package:** `habit_streaks`
- **Bundle ID:** `com.prompttostore.example.habitstreaks`
- **Platforms:** android, ios

## Summary

A habit tracker with daily check-offs and streaks, stored locally on the device.

## Screens

- **Today** — check off habits
- **Habit detail** — streaks and calendar
- **Add habit** — create/edit
- **Stats** — overview

## Decisions

- Material 3
- shared_preferences storage
- no backend
