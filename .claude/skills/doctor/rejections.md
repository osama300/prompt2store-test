# Known build failures and store rejections

Each item: **symptom → fix**. Numbers are stable so you can cite them ("doctor #21").
prompt-to-store specifics: test builds use workflow `p2s-android-test` (release APK signed with the debug key); release builds use `p2s-android-release` (upload key from the `p2s_android_signing` Codemagic variable group, created by `ship_release_build`) and `p2s-ios-release` (certificates/profiles created by `app-store-connect fetch-signing-files --create` from the `p2s_app_store` group). Build numbers come from Codemagic's `$BUILD_NUMBER`.

## App Store review rejections
**1.** Guideline 2.1 App Completeness - crashes/placeholder content/broken links/demo login missing. Fix: provide working demo account in appStoreReviewDetails, test release build on real device, remove "lorem ipsum" and TODO screens.
**2.** 2.3.x Inaccurate metadata/screenshots (screenshots show non-app content, other platforms' frames, ranking claims). Fix: device screenshots of real UI; no Android frames or "Best/#1" text; keywords without competitor names.
**3.** 4.0/4.2 Minimum Functionality - thin webview/Flutter template wrapper. Fix: add native-feeling features (push, offline, account), remove default counter demo.
**4.** 5.1.1 Privacy - missing privacy policy URL, no in-app account deletion (required if app supports account creation), unexplained permissions. Fix: add privacyPolicyUrl in appInfoLocalizations, in-app "Delete account", fill privacy nutrition labels in web UI.
**5.** 5.1.1(v)/Sign in with Apple (4.8) - third-party login (Google/Facebook) without equivalent privacy-preserving option. Fix: add Sign in with Apple or other compliant login option.
**6.** Missing/empty Info.plist purpose strings (ITMS-90683): NSCameraUsageDescription, NSPhotoLibraryUsageDescription, NSLocationWhenInUseUsageDescription, NSMicrophoneUsageDescription, NSUserTrackingUsageDescription (plugins like image_picker, geolocator, permission_handler). Fix: add descriptive strings (non-generic) for every plugin-requested permission; also remove plugin permission macros you don't use (permission_handler Podfile `PERMISSION_*=0`).
**7.** ATT: tracking SDK/IDFA use (ads, analytics) without NSUserTrackingUsageDescription / ATT prompt, or privacy labels inconsistent. Fix: add ATT prompt or remove SDK; make labels match.
**8.** 3.1.1 In-app purchase - digital goods sold via external payment/Stripe. Fix: use StoreKit (in_app_purchase plugin); restore purchases button; subscription terms/price/Terms of Use & Privacy links in paywall.
**9.** 2.5.x / ITMS-90338 non-public API or missing/forbidden symbols; ITMS-90809 deprecated UIWebView. Fix: update plugins, `flutter pub upgrade`, rebuild.
**10.** ITMS-90725/90713 SDK version requirement: must build with current Xcode/iOS SDK (Apple raises minimum yearly, typically April; currently Xcode 26 / iOS 26 SDK era). Fix: set Codemagic `environment.xcode: latest` (or specific current) and rebuild.
**11.** ITMS-90022/90023/90704 App icon problems: icon with alpha channel or missing 1024x1024. Fix: 1024x1024 PNG, no transparency, no rounded corners; use flutter_launcher_icons with `remove_alpha_ios: true`.
**12.** ITMS-90034 / "Missing Info.plist value" and ITMS-90189 duplicate build: CFBundleVersion must increase on every upload for a given version. Fix: Codemagic `$(app-store-connect get-latest-testflight-build-number ...) + 1` / `--build-number`.
**13.** Export compliance prompt blocks build processing/testing. Fix: Info.plist `ITSAppUsesNonExemptEncryption` = false (or PATCH build `usesNonExemptEncryption`).
**14.** 2.1 "Binary rejected - app crashed on launch on iPad" - Flutter default supports iPad; iPad layouts/permissions untested. Fix: test iPad simulator, or set TARGETED_DEVICE_FAMILY=1 for iPhone-only (then no iPad screenshots needed).
**15.** 5.2/ 4.1 Copycat / 1.2 UGC without report/block/moderation. Fix: add reporting, blocking, EULA, contact info.
**16.** Metadata rejected: missing support URL page, privacy URL 404, description mentions other platforms ("Android"), beta text like "beta/test" in the name. Fix: valid working URLs; strip platform mentions.
**17.** Age rating questionnaire outdated (Apple revamped ratings in 2025: new 13+/16+/18+ tiers and extra questions); submission blocked until answered. Fix: PATCH ageRatingDeclaration with current fields via preflight.
**18.** Account: agreements not accepted (403 REQUIRED_AGREEMENTS_MISSING_OR_EXPIRED); app has no price/availability set; app privacy "data usage" not published. Fix: account holder accepts in portal; set price schedule; complete privacy questionnaire in UI.

## Google Play rejections
**19.** Target API level too low: new apps/updates must target a recent API (currently API 35 for 2025 deadline; 36 expected for Aug 2026). Fix: Flutter -> update Flutter SDK/`compileSdk`/`targetSdk` in android/app/build.gradle; `flutter.targetSdkVersion`.
**20.** versionCode already used / not increased. Fix: `--build-number` from Codemagic `$(google-play get-latest-build-number ...) + 1` or `BUILD_NUMBER`.
**21.** Signed with wrong/debug key ("signed in debug mode" / "wrong key"). Fix: configure `android/key.properties` signing from Codemagic keystore reference (`android_signing`), release not debug build config; match Play upload key.
**22.** Must upload AAB not APK (`flutter build appbundle --release`). Also 64-bit requirement: ensure arm64 libs (Flutter default OK; some native plugins ship only armeabi-v7a).
**23.** Draft app errors: "Only releases with status draft may be created on draft app" - use status `draft` until first Console publish; complete store listing, content rating, target audience, data safety, app access, ads declaration, government/news/financial declarations in Console (API cannot do these).
**24.** Developer account requirement: personal accounts created after Nov 2023 need closed test (12+ testers for 14 days) before production; org accounts need D-U-N-S verification. Fix: run closed track first, tell user timeline.
**25.** Policy: missing/invalid privacy policy URL, data safety form inconsistent with SDKs (AdMob, Firebase Analytics, Crashlytics), unaccounted permissions (READ_SMS, background location, MANAGE_EXTERNAL_STORAGE, QUERY_ALL_PACKAGES, photo/video permissions READ_MEDIA_*). Fix: remove permissions via `tools:node="remove"` in AndroidManifest, declare in data safety.
**26.** Account deletion requirement: apps with accounts must offer in-app and web account-deletion URL (data safety). Fix: add flow and URL.
**27.** Store listing violations: keyword stuffing in title/short desc, emojis/ALL CAPS, "#1"/price claims, screenshots with device frames of other platforms, icon badges; metadata limits exceeded (title 30, short 80). Fix: clean text; use flat screenshots.
**28.** Permission `AD_ID` / Advertising ID declaration missing when targeting API 33+ and using ads SDK. Fix: add `<uses-permission android:name="com.google.android.gms.permission.AD_ID"/>` and declare, or remove.
**29.** Crash/ANR above bad-behavior thresholds in vitals (user-perceived crash >1.09%, ANR >0.47% overall) reduces visibility; pre-launch report crashes. Fix: fix Crashlytics top crashes, upload ProGuard/R8 mapping + native symbols (`--obfuscate --split-debug-info`, upload via deobfuscationFiles).
**30.** API 403/permission propagation, wrong service-account role; edits.commit fails with "changesNotSentForReview" requirement when managed publishing enabled. Fix: set the param true and publish in Console.

## Build failures (Codemagic / Flutter)
**31.** Xcode/CocoaPods mismatches: "CocoaPods could not find compatible versions", `pod install` fails after plugin upgrade, M1/ARM. Fix: `cd ios && pod repo update && pod install` in script, delete `ios/Podfile.lock`/Pods, set `platform :ios, '13.0'` (min iOS per plugins), pin `cocoapods: default` in environment.
**32.** Code signing: "No profiles for 'com.x' were found", wrong distribution cert, provisioning not matching bundle id, cert limit reached. Fix: use Codemagic `ios_signing: distribution_type: app_store, bundle_identifier` with App Store Connect API key integration (automatic cert/profile fetch/creation, `app-store-connect fetch-signing-files "$BUNDLE_ID" --type IOS_APP_STORE --create`, then `keychain initialize` and `xcode-project use-profiles`); revoke stale certs.
**33.** Missing `integrations.app_store_connect` / publishing credentials: "Unauthorized" on upload. Fix: add API key (Issuer, Key ID, .p8) in Codemagic Team > Integrations; reference by name in yaml; ensure key role >= App Manager.
**34.** Google Play publishing from Codemagic fails: need `GCLOUD_SERVICE_ACCOUNT_CREDENTIALS` group var (full JSON) and `google_play: credentials: $GCLOUD_SERVICE_ACCOUNT_CREDENTIALS, track: internal, submit_as_draft: true` (draft until first publish). 
**35.** Gradle/Java mismatches: "Unsupported class file major version", AGP requires JDK 17; Kotlin/Gradle plugin versions. Fix: Codemagic `java: 17` (or per AGP), upgrade Flutter's `settings.gradle` plugin block, `flutter upgrade`/`flutter pub get` before build.
**36.** Flutter version drift: `flutter: stable` moves and breaks deps ("Dart SDK version" constraints). Fix: pin `flutter: 3.x.y` in codemagic.yaml, commit `pubspec.lock`.
**37.** Wrong yaml: workflow `triggering`/`branch_patterns`, missing `instance_type: mac_mini_m2` for iOS (Linux can't build iOS), build timeout (`max_build_duration` default 60 min; free minutes exhausted).
**38.** Android keystore: `key.properties` not generated in CI; `storeFile` path wrong. Fix: use `android_signing: - keystore_reference` and script writing `$CM_KEYSTORE_PATH` / `$CM_KEYSTORE_PASSWORD` / `$CM_KEY_ALIAS` / `$CM_KEY_PASSWORD` into `android/key.properties`.
**39.** Plugin permissions merge/min SDK: "minSdkVersion X cannot be smaller than version Y" — set `minSdkVersion` to plugin requirement (Firebase 23+); iOS deployment target in Podfile + Xcode project (`IPHONEOS_DEPLOYMENT_TARGET`) must agree.
**40.** `flutter build ipa` export options: use `--export-options-plist=/Users/builder/export_options.plist` generated by `xcode-project use-profiles`; missing => "exportArchive: No signing certificate". Missing `--build-name/--build-number` => duplicate version rejection.
**41.** Missing secrets (dart-define, google-services.json, GoogleService-Info.plist) in repo: build passes locally, fails in CI. Fix: inject from env vars (base64) in script step.
